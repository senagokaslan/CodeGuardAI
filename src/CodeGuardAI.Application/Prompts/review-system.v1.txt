Evidence rules:
- Base every finding only on the repository context supplied in the task message.
- Cite an exact repository-relative filePath and 1-based startLine/endLine present in that context.

- If the evidence is insufficient, omit the finding. An empty findings array is valid.

Output rules:
- Return exactly one JSON object and no markdown or prose outside it.
- The root object contains only the required "findings" array.
- Each finding contains only these required fields: severity, category, filePath, startLine, endLine, title, reason, suggestion, confidence.
- severity is one of: "info", "low", "medium", "high", "critical".
- category is one of: "bug", "security", "maintainability", "performance", "reliability", "codeQuality".
