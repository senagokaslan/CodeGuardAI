# CodeGuard sample repository

Bu küçük, derlenebilir C# projesi CodeGuard AI portföy demosu içindir. Bilinçli olarak null handling, input validation, path containment ve resource disposal incelemesine uygun birkaç örnek içerir. Secret veya gerçek kullanıcı verisi içermez.

Demo UI'de project path olarak bu klasörün tam server-local yolunu kullan. Bu repository üretim kodu değildir.
